# 🌟 AgilCris Consultoria - Link na Bio

---

## 📱 Sobre o Projeto

Este é um **Link na Bio profissional** para a consultoria **AgilCris**, desenvolvido para centralizar todos os canais de atendimento e produtos digitais em um único lugar.

### ✨ Funcionalidades

- ✅ Design elegante com tom dourado e terroso
- ✅ Totalmente responsivo (funciona em celulares, tablets e desktop)
- ✅ Botões integrados diretamente com WhatsApp
- ✅ Animações suaves e carregamento rápido
- ✅ Perfil profissional com foto, nome e biografia
- ✅ Seção de serviços: Planilhas, Consultoria, Guia Financeiro
- ✅ Indicadores de confiança (atendimento humanizado, foco, simplicidade)
